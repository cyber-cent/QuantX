# World Cup Match Data

The source repository did not include the underlying CSV, so no match dataset has been copied into QuantX.

To run the analysis, place a verified match-level CSV here named `matches_1930_2022.csv`. The scripts expect at least these columns:

- `Year`: World Cup tournament year
- `home_score`: goals scored by the home-designated team
- `away_score`: goals scored by the away-designated team

Verify the dataset's source, coverage, missing values, and match count before interpreting results. Do not assume the dataset is an official FIFA dataset unless its provenance confirms that.
